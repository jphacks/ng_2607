# キャラクターのベース画像

ストーリーの画像を生成するとき、参照画像として使うキャラクターの絵を置くフォルダです。ここに画像があるキャラは、その絵と同じ絵柄・同じ見た目で描かれ、キャラ自身も絵に写るようになります。画像がないキャラは、人物の顔を写さない写真風になります。

## 置き方

- ファイル名は **キャラ用アカウントのハンドル + 拡張子** にします（小文字）。
  - 例: `yukimemori.bsky.social.png`
- 形式は PNG・JPEG・WebP（拡張子 `.png` `.jpg` `.jpeg` `.webp`）、**2MB まで**。
- 1キャラにつき1枚です。
- 管理画面（`/characters`）の「画像生成のベース画像」から選んでも、このフォルダに保存されます。

ファイルを置いたり差し替えたりしたら、サーバーの再起動なしで次の生成から使われます。

## 共有

このフォルダは Git で管理しているので、コミットするとチーム全員の PC で同じベース画像が使われます。

- 画像は生成のたびに OpenAI に送られます。自作の絵など、使ってよい画像だけを置いてください。
- 差し替えたときは、`git diff --stat` で意図したファイルだけが変わっているか確認してからコミットしてください。
